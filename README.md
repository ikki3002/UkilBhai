# Ukil Bhai (উকিল ভাই)

> **আপনার ডিজিটাল আইনি সহায়ক**  
> A modern native Android legal assistance and consultation application tailored for Bangladesh legal contexts. Built with Java, Material 3, and a Linear-style dark theme.
